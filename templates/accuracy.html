How this test works
  • Recognised: each stored sample is matched against the others, after removing it and its {{ report.window }} nearest frames on each side (so near-identical frames don't inflate the score).
  • Stranger accepted: each voter is removed completely and their samples are matched against everyone else. A good system rejects them all.
  • Distances: typical same-person distance {{ report.genuine_distance }}, typical stranger distance {{ report.impostor_distance }}. The threshold {{ threshold }} should sit between them.
  • Liveness check: {{ 'ON — voters must close and open their eyes' if liveness else 'OFF' }}.
  • Limits: samples come from one session per voter, so real-world accuracy (different day, lighting) will be lower.
